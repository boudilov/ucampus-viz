# UCampus — Real-time визуализация

Прототип «солнечной системы» активности UCampus. Разрабатывается поэтапно.

## Структура

```
ucampus-viz/
├── index.html        — визуализация (открывать в браузере)
├── data/
│   └── workshops.json — справочная информация по мастерским
└── README.md
```

`data/workshops.json` — сюда можно добавлять любую справочную информацию
по мастерским (описание, адрес/этаж, требования к допуску, фото и т.д.).
Сейчас в визуализации используются только `id` и `name`; остальные поля
зарезервированы под будущее развитие (например, всплывающие карточки
при наведении на мастерскую).

## Что уже сделано

- Чёрный фон (#080808), случайное звёздное поле, медленное вращение всей
  сцены вокруг центра.
- 13 мастерских на случайных орбитах вокруг центра, у каждой своя
  скорость и направление вращения.
- Тонкие линии орбит (включены по умолчанию).
- Подписи названий мастерских (выключены по умолчанию).

## Управление (пока для отладки, потом станет UI-панелью)

| Клавиша | Действие                          |
|---------|-------------------------------------|
| `L`     | показать/скрыть названия мастерских |
| `O`     | показать/скрыть линии орбит         |
