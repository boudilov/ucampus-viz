# UCampus — Real-time визуализация

Прототип «солнечной системы» активности UCampus. Разрабатывается поэтапно.

## Структура

```
ucampus-viz/
├── index.html          — визуализация (открывать в браузере)
├── data/
│   └── workshops.json  — справочная информация по мастерским
├── .claude/
│   └── launch.json     — конфиг локального сервера для превью
└── README.md
```

`data/workshops.json` — 14 мастерских с полями `id`, `name`, `websocket_id`
(зарезервирован под будущее подключение к бэкенду), `short_name`, `size`
(влияет на размер точки на сцене) и `position` (порядок орбит от центра
наружу). Подгружается через `fetch` — при открытии `index.html` напрямую
как `file://` браузер блокирует локальный `fetch`, поэтому для работы с
актуальными данными нужен локальный сервер (см. «Как запустить»).

## Как запустить

```bash
cd ucampus-viz
python -m http.server 8935
```

Открыть `http://localhost:8935` в браузере.

### Пользователи и событийная модель
Полностью эмулируемая (пока без WebSocket) событийная модель жизненного
цикла пользователя:

- `user.appeared` — появление маленькой точкой на внешнем контуре,
  вращение со случайной скоростью/направлением.
- `user.booking.init` — перелёт по прямой на орбиту случайной мастерской.
- в диалоге бронирования пользователь вращается по маленькой орбите
  вокруг самой мастерской (а не «приклеен» к общей орбите).
- `user.booking.created` — самое важное событие: пользователь пролетает
  по прямой через центр сцены, не останавливаясь, а в момент прохождения
  центра срабатывает крупная неподвижная вспышка (с лучами-звездой и
  расширяющимся кольцом, в чёрно-белом минималистичном стиле) — и летит
  дальше, на внешний контур с другой стороны.
- `user.booking.cancelled` / `user.booking.blocked` — возврат на внешний
  контур (блокировка сопровождается небольшой красноватой вспышкой).
- `user.exit` — плавное затухание и уход с сайта.
- Кометный шлейф — только во время перелётов между орбитами, чтобы не
  захламлять картинку в стабильном вращении.

### UI
- Подпись `UCAMPUS LIVE` в левом верхнем углу.
- Модальное окно со списком горячих клавиш — по клавише `I` или клику на
  иконку «i» в левом нижнем углу.
- Панель настроек эмуляции (правый нижний угол, чёрно-белый минимализм,
  тонкие линии): переключатель эмуляции вкл/выкл (по умолчанию выключена)
  и ручной ввод основных параметров — интервал появления пользователей,
  время до решения на контуре, шанс открыть бронь, время у мастерской,
  шансы подтверждения/блокировки брони. Все правки применяются на лету.
- Панель статистики (правый верхний угол, в одну строку, без рамок, в
  стиле `UCAMPUS LIVE`): пользователей на сцене, подтверждено/отменено/
  заблокировано броней, ушло с сайта.

## Управление

| Клавиша | Действие                                  |
|---------|--------------------------------------------|
| `L`     | показать/скрыть названия мастерских         |
| `O`     | показать/скрыть линии орбит                 |
| `M`     | показать/скрыть «звёзды» мастерских         |
| `U`     | показать/скрыть id пользователей            |
| `R`     | включить/выключить вращение фона            |
| `I`     | показать/скрыть окно с горячими клавишами   |
